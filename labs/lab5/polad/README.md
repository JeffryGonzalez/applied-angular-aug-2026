# The app you inherited

> **This code is deliberately bad.** It exists to be diagnosed, not copied. If you
> have arrived here looking for an example of how to build an Angular
> application, you want `../instructor/` instead.

It is not bad in a cartoonish way, and that's the point. Every wrong thing in
here has a reason a competent person could say out loud on a Tuesday without
embarrassment, which is exactly why nobody stopped it. Some of what looks wrong
is fine. Working out which is which is the lab.

Sheriff is installed and configured. It is not, at the time you receive this,
telling anyone anything — nothing runs it.

```
npx sheriff verify src/main.ts
npx eslint src/app
```

Domain: an internal help desk. Tickets, and the agents they're assigned to.
